# ForkFit release: 2026-10-11

## Scope

- Preserve local plan drafts, single-recipe task state and shopping selections across refreshes.
- Preserve discovery return paths, prevent stale filter responses, and correct misleading form states.
- Support cancelling pending plan changes, persist confirmations and prevent stale-version retries.
- Correct locked-day scope, clarification/retry context, method-change routing and utensil constraints.
- Validate patch value types, distinguish technical failures from questions requiring user input, and keep recipe names consistent with edits.
- Use `deepseek-v4.1-flash` for planning, adaptation and extraction.

## Verification

- Python 3.12 backend suite: 168 tests, 159 passed and 9 skipped.
- ESLint with zero warnings, application TypeScript and E2E TypeScript checks passed.
- Production Next.js build passed, targeting `http://127.0.0.1:8000` for the VPS backend proxy.
- Minimal real JSON call with `deepseek-v4.1-flash` succeeded locally. This is connectivity verification, not a full quality evaluation of the new model.
- Recent real-browser evidence, including locked-day preservation, local recipe modification, refresh recovery and undo, is recorded in `browser-audit-2026-09-23.md`.
- The complete automated browser suite was not rerun for this release. Earlier successful recipe edits used the previous model.

## Deployment Safety

- Verify production application files against the previous release before replacing changed files.
- Preserve the production-only edit to `scripts/verify_agents_v3_real.py`; do not replace environment credentials, uploads, recipes or unrelated services.
- Back up changed files, the previous frontend artifact, backend environment and PostgreSQL before switching.
- No dependency or schema change is included. Restart only ForkFit backend and frontend.
- Store the deployed commit, artifact checksums, backup path and outcome in `/srv/forkfit/release.json`.
- On failure, restore application files, frontend artifact and backend environment. Do not restore a database dump over newer user data.

## Remaining Limits

Ingredient quantities and image/content accuracy are not resolved by this release. Broad multi-day replanning, arbitrary conversational phrasing and model output quality still require further evaluation. Passing checks does not mean the product is defect-free.
